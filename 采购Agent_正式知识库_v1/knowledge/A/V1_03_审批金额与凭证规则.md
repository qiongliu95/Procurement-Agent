# 审批金额与凭证规则

> 适用范围：采购 Agent 演示系统。以下为项目已确认业务规则的解释。

## 审批金额分界
采购申请金额小于或等于10000元时，由 M01 单级审批。金额超过10000元时，必须先由 M01 批准，再由 M02 批准；M01 未批准前，M02 不得完成审批。恰好10000元属于 M01 单级审批，不要求高金额报价凭证。

## 报价凭证的含义
超过10000元的申请在 M02 最终批准前必须核验可信报价凭证；允许先提交并完成 M01 初审。凭证核验不能替代 M01 批准。当前演示系统由有权限的人工审批角色通过服务端凭证核验动作记录凭证状态，不解析附件正文，不提供 OCR 或自动真实性鉴别。不能仅因用户说“我有报价”就假设系统已收到合格凭证。

## 审批权限与动作
审批须由相应人工角色执行，Agent 无权代替审批人通过或拒绝。高金额 M01 批准后只进入待 M02，不代表最终批准；两级批准必须属于同一申请当前版本，版本变化后旧批准及凭证不继续生效。PO 创建前复核完整审批条件。员工询问“这笔采购谁审批”可以解释金额规则；询问“我的 PR-XXX 现在由谁审批”则必须读取真实申请状态，区分当前审批人与最终审批级别，不得以静态规则代替业务记录。

## 金额例子
9999.99元及10000.00元：M01；10000.01元及15000元：先 M01、后 M02，最终批准前须核验报价凭证。示例仅解释系统配置的金额规则，不代表真实企业采购制度。
