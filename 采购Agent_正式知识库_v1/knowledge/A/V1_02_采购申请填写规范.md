# 采购申请填写规范

> 适用范围：采购 Agent 演示系统。以下为项目已确认业务规则的解释。

## 创建采购申请的必要信息
当前 MVP 为单品类、单条目、人民币 CNY 的采购申请。员工只需提供商品、有效正整数数量和采购用途。供应商与当前有效采购单价由系统从 Backend 唯一商品目录记录自动读取，不要求员工填写。采购用途必须非空，不作语义充分性判断。目录缺记录、停用、缺供应商或有效采购价、供应商黑名单、无法唯一确定商品时，不创建草稿，提示联系采购负责人在后台维护后再申请。

## 字段来源与可信性
申请人及部门应来自认证会话；币种来自租户配置；预算科目来自已授权部门映射。Agent 不得猜测用户部门、预算科目或申请人身份。缺少可信映射时应追问或阻断。

## 预算和单价不能混淆
“我最多花7000元”是预算上限，不等于每件商品单价。金额按数量乘目录有效采购单价计算；口头价格、预算、历史成交价和旧目录参考价均不能替代正式有效采购价。目录一项具体商品唯一记录，由采购负责人或现有授权采购管理角色 M01/M02 维护供应商与有效采购价，不作比价或自动供应商推荐。

## 写入前确认
在创建或提交前，向用户展示将要写入的关键字段和具体动作，取得明确确认。仅询问流程、预算、价格或选型建议时不得触发确认写入。

## 当前不支持的能力
本 MVP 不提供多条目采购、自动报价比选、OCR 识别或直接创建 PO。涉及这些需求，应说明当前系统能力边界。
