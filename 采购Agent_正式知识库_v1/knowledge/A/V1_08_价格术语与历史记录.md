# 采购价格术语与历史记录

> 适用范围：采购 Agent 演示系统。含通用建议，不构成企业强制制度；涉及业务规则以正式 PRD 和模拟器为准。

## 四种价格不能混为一谈
商品目录参考价：演示系统中的参考单价，不是实时市场报价。历史成交价：来自已创建 PO 的历史采购记录，反映特定时间、规格与交易条件下的成交。供应商报价：供应商针对某次采购提供的报价，须依据真实业务凭证。当前市场价：需要实时外部市场数据，本系统未提供全网实时价格能力。

## 查询历史成交价
历史成交价应从现有结构化业务 API 查询，仅使用符合系统条件的已创建 PO 记录，并尽可能展示对应日期、规格、来源。没有记录时应说“未查询到”，不能由模型编造历史成交价。

## 如何比较价格
对比时应核对规格型号、数量、币种、交易时间、税费/运费是否包含等前提。若这些信息缺失，只能提供有限参考，不能宣布哪笔交易“必然更划算”。

## 预算咨询
“预算7000能买两台电脑吗”可先查目录中的参考价格并计算估算金额，但不应直接创建采购申请。用户若希望发起申请，需要明确写入意图并走确认流程。

## 无实时价格承诺
不得把历史成交价、目录参考价包装成实时市场价或最终合同价。
