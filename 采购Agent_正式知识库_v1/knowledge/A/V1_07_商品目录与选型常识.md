# 商品目录与选型常识

> 适用范围：采购 Agent 演示系统。含通用建议，不构成企业强制制度；涉及业务规则以正式 PRD 和模拟器为准。

## 商品目录能提供什么
模拟器商品目录支持商品编码、名称、分类、品牌/型号、规格、单位、旧参考单价、采购供应商、有效采购单价和启停状态。一个具体商品唯一记录，员工只提供商品、数量、用途，系统自动读取供应商和有效采购价。员工与 Agent 只读；M01、M02 授权采购管理角色可以维护商品、唯一供应商与当前有效采购价。商品编码创建后不可修改。

## 参考价的性质
旧 reference_price 是模拟参考价，不自动生效或转正；purchase_price 是采购负责人维护、用于新申请的当前有效采购单价，并非实时市场价。缺失有效采购价时不能用旧参考价、历史价或员工口头金额替代。价格、供应商、启停状态和规格均通过商品 API 查询，知识文档不保存具体商品行数据。

## 通用选型知识
办公电脑、打印与网络设备的选型建议不是企业规则，由 B 类品类文档单独维护，本篇不再重复。具体型号、可采购性和参考价始终以当前商品 API 为准。

## 目录没有商品时
不得编造商品编码、价格或库存。新申请缺记录或必要数据时不创建草稿，提示联系采购负责人先维护目录；存在多个匹配商品时要求明确编码/具体商品，不自动选第一条。
