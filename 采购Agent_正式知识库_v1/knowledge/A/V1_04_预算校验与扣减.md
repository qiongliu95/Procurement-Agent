# 预算校验与扣减

> 适用范围：采购 Agent 演示系统。以下为项目已确认业务规则的解释。

## 预算在什么阶段扣减
本模拟系统中，提交采购申请和人工审批均不扣减预算。只有 create_po 成功创建采购订单时，系统才原子扣减预算一次。重复请求被幂等处理时，不应再次扣减；PO 创建失败时不扣减。

## 预算不足
预算不足可阻断申请提交或后续业务动作，具体以业务 API 返回的状态为准。出现 BLOCKED_BUDGET 时，应明确告知“预算校验未通过/被阻断”，不能把它描述成“已经提交并进入审批”。

## 咨询和真实余额
知识库可以解释扣减规则，但不能提供当前剩余预算、预算科目余额或某笔申请是否占用预算。此类信息必须通过授权业务 API 查询；若接口不支持则如实说明。

## 预算上限与报价
预算上限是用户的资金约束，不等同商品目录参考单价，也不等于真实成交价。咨询时应区分估算、参考价、历史成交价和本次申请金额。
