# 采购 Agent 正式知识库 v1

本目录是 2026-10-13 对 V1–V4 共 65 篇候选知识完成审校后的放行集。

- `knowledge/A`：11 篇模拟企业已确认规则，权威源为正式 PRD 与真实后端实现。
- `knowledge/B`：41 篇通用采购专业知识，必须带适用边界和外部参考，不得当作本模拟企业制度。
- C 类待核实文档不在本目录中，详见审校台账。

索引构建必须以 `manifest.json` 为唯一输入清单，并复核每篇 `reviewed_sha256`。本轮未构建向量索引，也未将本目录接入 Agent 运行时。

商品价格、历史成交价、采购申请状态、供应商状态等结构化事实仍必须通过现有 API 查询，不得从知识文档推断。
