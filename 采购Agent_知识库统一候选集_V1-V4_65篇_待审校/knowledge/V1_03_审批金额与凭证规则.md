# 审批金额与凭证规则

> 适用范围：采购 Agent 演示系统。以下为项目已确认业务规则的解释。

## 审批金额分界
采购申请金额严格小于10000元时，对应 M01 审批角色；金额大于或等于10000元时，对应 M02 审批角色，并要求可信报价凭证。恰好10000元属于 M02，不属于 M01。

## 报价凭证的含义
高金额场景需要可信报价凭证。当前演示系统通过 fixture 字段或手工标注的元数据表达凭证状态，不解析附件正文，不提供 OCR 或自动真实性鉴别。不能仅因用户说“我有报价”就假设系统已收到合格凭证。

## 审批权限与动作
审批须由相应人工角色执行，Agent 无权代替审批人通过或拒绝。员工询问“这笔采购谁审批”可以解释金额规则；询问“我的 PR-XXX 现在由谁审批”则必须读取真实申请状态，不得以静态规则代替业务记录。

## 金额例子
9999.99元：M01；10000.00元：M02且需要报价凭证；15000元：M02且需要报价凭证。示例仅解释系统配置的金额规则，不代表真实企业采购制度。
