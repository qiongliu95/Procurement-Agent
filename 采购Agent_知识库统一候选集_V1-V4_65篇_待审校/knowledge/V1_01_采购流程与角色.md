# 采购流程与角色

> 适用范围：采购 Agent 演示系统。以下为项目已确认业务规则的解释。

## 采购流程概览
本模拟企业采购系统采用“需求咨询—创建申请—提交—人工审批—采购执行”的分工。员工可以先咨询制度或商品，再明确要求创建采购申请；咨询本身不构成提交申请的授权。

## Agent 可以做什么
Agent 可读取采购规则和业务状态，协助整理申请字段，按用户明确指令创建、查询、修改申请，或在用户确认后提交已有 DRAFT。涉及写入的操作必须经过既有确认流程，并遵守服务端权限、版本与幂等校验。

## Agent 不可以做什么
Agent 不代替审批人批准或驳回，也不直接创建采购订单 PO。人工审批、供应商准入、PO 创建由对应业务角色或模拟器流程负责。回答“帮我审批”时，应说明权限边界，而不是假装操作成功。

## 典型办理路径
用户说“我打算买两台电脑，预算约7000元”属于计划或咨询，不应自动创建申请。用户明确说“帮我新建采购申请”时，Agent 可进入字段补齐和确认流程。提交后需读取业务系统返回的真实状态，不能仅凭模型回复判断提交成功。

## 适用边界
这是采购 Agent 演示系统的流程说明，不代表现实企业或法律通用要求。具体采购申请编号、当前审批人和办理进度，必须调用业务 API 查询。
