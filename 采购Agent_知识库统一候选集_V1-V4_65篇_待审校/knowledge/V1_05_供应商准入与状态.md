# 供应商准入与状态

> 适用范围：采购 Agent 演示系统。以下为项目已确认业务规则的解释。

## 供应商状态
模拟器使用 active、new、blacklisted 等供应商状态。active 供应商可继续符合其他规则的采购流程；new 供应商需进入人工准入流程，未经准入不可直接创建 PO；blacklisted 供应商为硬阻断，不得绕过。

## 新供应商怎么办
用户可了解准入要求或提交需人工处理的业务信息，但 Agent 不得自行宣布供应商已审核通过。供应商是否准入、当前状态如何，以模拟器业务 API 为准。

## 黑名单为什么不能采购
黑名单是已确认的系统级业务阻断规则。即使用户明确要求“忽略黑名单”，Agent 也不得绕过服务端限制。

## 供应商与商品的关系
当前商品目录独立维护，没有商品—供应商关联表，也没有库存或实时报价关联。因此不能仅凭某个商品存在于目录中，就断定哪家供应商有货或报价最低。

## 权限边界
供应商审核与采购订单执行由授权人工角色完成，Agent 只能协助咨询、读取或受控处理其获准的申请动作。
