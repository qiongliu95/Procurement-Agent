# 采购常见问题速查

> 适用范围：采购 Agent 演示系统。含通用建议，不构成企业强制制度；涉及业务规则以正式 PRD 和模拟器为准。

## 申请类
**Q：只是想了解采购流程，会创建申请吗？** 不会。咨询与计划不代表明确写入授权。

**Q：采购用途必须写得很详细吗？** 当前系统只要求非空文本，不执行语义充分性校验。

**Q：能一次申请多种商品吗？** 当前 MVP 仅支持单条目，不能把多条目请求伪装成已支持。

**Q：采购申请已提交，能否直接算采购完成？** 不能。提交、审批、创建 PO 是不同业务阶段。

## 审批类
**Q：金额恰好10000元归谁？** M02，且需要可信报价凭证。

**Q：Agent能帮我批准吗？** 不能。审批必须由授权人工角色执行。

**Q：申请提交就扣预算吗？** 不扣。仅成功创建 PO 时原子扣减一次。

## 商品与供应商类
**Q：商品目录参考价是市场价吗？** 不是，它是模拟参考值。

**Q：新供应商可以直接下单吗？** 未经人工准入不能创建 PO。

**Q：黑名单供应商可否破例？** 不可以，系统硬阻断。

**Q：为什么目录有商品却不知道哪家供货？** 当前目录没有商品与供应商关联。

## 记录与异常类
**Q：可以查询某笔申请当前进度吗？** 可以尝试通过业务 API 查询真实记录，知识库不保存实时进度。

**Q：已创建 PO 的申请能修改吗？** 不能。

**Q：预算阻断是不是进入审批了？** 不是，应根据业务返回结果解释阻断。

**Q：查不到历史成交价怎么办？** 说明未查询到符合条件的记录，不能编造。
