# 采购申请填写规范

> 适用范围：采购 Agent 演示系统。以下为项目已确认业务规则的解释。

## 创建采购申请的必要信息
当前 MVP 为单品类、单条目、人民币 CNY 的采购申请。用户需要提供数量、单价、供应商和采购用途等必要信息。采购用途必须是非空文本；系统当前不做用途语义充分性判断，不能把“市场部本月使用”擅自判为无效。

## 字段来源与可信性
申请人及部门应来自认证会话；币种来自租户配置；预算科目来自已授权部门映射。Agent 不得猜测用户部门、预算科目或申请人身份。缺少可信映射时应追问或阻断。

## 预算和单价不能混淆
“我最多花7000元”是预算上限，不等于每件商品单价。数量与单价用于计算申请金额，不能用用户口头预算直接填充单价。商品目录参考价可用于咨询，不自动等于本次采购的确认报价。

## 写入前确认
在创建或提交前，向用户展示将要写入的关键字段和具体动作，取得明确确认。仅询问流程、预算、价格或选型建议时不得触发确认写入。

## 当前不支持的能力
本 MVP 不提供多条目采购、自动报价比选、OCR 识别或直接创建 PO。涉及这些需求，应说明当前系统能力边界。
