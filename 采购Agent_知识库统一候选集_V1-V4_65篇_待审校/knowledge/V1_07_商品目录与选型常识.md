# 商品目录与选型常识

> 适用范围：采购 Agent 演示系统。含通用建议，不构成企业强制制度；涉及业务规则以正式 PRD 和模拟器为准。

## 商品目录能提供什么
模拟器商品目录支持商品编码、名称、分类、品牌/型号、规格、单位、参考单价和启停状态。员工与 Agent 可只读查询；M01、M02 管理员可以新增、编辑、启用或停用商品。商品编码创建后不可修改。

## 参考价的性质
目录中的价格是模拟参考单价，不代表当前市场报价、合同报价或历史成交价。商品价格、是否启用、具体规格应通过商品 API 查询，知识文档不维护具体商品行数据。

## 办公电脑选型
通用办公场景可优先核对办公软件、浏览器多标签、视频会议、内存、固态硬盘、显示接口及售后要求；数据分析或设计工作可能需要更高配置。具体型号、可采购性和参考价应以当前目录为准。此为通用选型建议，不是强制采购标准。

## 打印与网络设备选型
打印设备可考虑打印量、黑白/彩色、双面、耗材和连接方式；网络设备可考虑端口、速率、管理能力与部署环境。采购前应由业务使用方明确实际需求。

## 目录没有商品时
不得编造商品编码、价格或库存。可以提示用户补充规格、查询相近商品或联系管理员维护目录。
