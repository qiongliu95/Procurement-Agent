# 采购Agent知识库 V1–V4 统一候选集

**65篇候选 Markdown 知识文档，非已验收生产知识库。**

- V1 11篇：模拟采购规则与操作咨询
- V2 16篇：采购专业通用方法
- V3 18篇：商品品类选型
- V4 20篇：复杂采购场景

此包把4个批次原文统一收集，**没有擅自删除、重写或推断规则**。所有文件保持原始内容及来源元数据，避免误把文档数量相加视为有效知识数量。

## 使用
1. 阅读 `交叉主题审查清单.md`。
2. 由Codex对照当前本地正式PRD、SQLite后端规则和真实 Agent READ 工具逐项核查；标记冲突、失效、无法核实的来源。
3. 重要重叠知识先确定唯一权威答案（V1确认制度 > 通用参考），保留通用方法与业务场景的不同解释维度。
4. 仅将审校通过的 `knowledge/*.md` 建入**中文语义索引**，保留文档ID、章节与来源；README与审查清单不要进索引。
5. 价格、供应商状态、采购申请、审批状态等实时或结构化数据只读现有API。

## 当前审查结论
- 文件计数、ID唯一性、ZIP完整性可自动核验；这些不等于事实与来源已通过人工审校。
- 按标题识别多个主题重叠簇；通用方法+情境案例的重复应去冗余，不宜整篇删除。
- V2–V4 有部分参考来源只支撑大框架，不可将其当作每个案例的逐条证明。
- 尚未核对用户本机正式PRD、服务器最新业务逻辑或检索有效性。
